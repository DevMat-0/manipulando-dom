Conhecendo o DOM

O que é o DOM

O DOM (Document Object Model) é uma representação da pgaina do HTML que o navegador cria na memoria.

Ele permite que Javascript leia, altere, adicione e remova elementos da pagina.

Conexao dos elementos:

  • HTML: É o arquivo que você escreve/li>
  • DOM: É a arvore de objetos que o navegador cria a partir desse HTML
  • Javascript: Usa o DOM para interagir com a pagina
